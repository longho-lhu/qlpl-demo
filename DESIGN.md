# Design

## Product mode

Operate

## Design intent

The product should feel like a calm, trustworthy operations dashboard: precise, controlled, and easy to scan. It should communicate room health and machine state immediately without looking like a generic marketing-style app.

## Visual direction

- prioritize information hierarchy over decoration;
- use a soft blue-violet palette with restrained accent colors for status states;
- keep cards structured and legible; avoid excessive nested surfaces;
- favor consistent spacing and alignment over novelty;
- use subtle depth only to support structure, not to create loud visual effects.

## Typography

Use a clean, modern sans-serif system stack. Keep labels compact and uppercase where useful, while dashboard numbers remain bold and highly legible.

## Color system

- background: cool gray-blue with subtle gradients;
- primary action: blue-violet gradient for emphasis;
- success state: green;
- warning: amber;
- critical: red;
- neutral surfaces: white with soft borders and low-contrast shadows.

## Layout and spacing

- broad section spacing with tight internal grouping;
- clear separation between top bar, navigation, and content cards;
- stat cards should be consistent in size and rhythm across the dashboard;
- chart rows and usage bars should have strong alignment and clear value labels.

## Components

- stat cards with icon, value, and supporting text;
- segmented status rows with percentage bars;
- glass panels for the page shell and app chrome;
- role chip for admin/user state;
- compact, functional controls with strong hover and focus states.

## Quality bar

The dashboard should feel operationally polished: data should be legible, states should be obvious, and the interface should not distract from the task at hand.
